# 📖 Concept Notes

This directory contains my notes on individual AI engineering concepts.

Each concept is written in my own words after researching, explaining, receiving feedback, and refining my understanding.

Every note follows a consistent structure:

- Hook
- What is it?
- Why does it matter?
- How does it work?
- Example
- Common misconceptions
- Final thought
- References

The objective is to build understanding—not merely collect definitions.
